# WebBoard

Веб-приложение «Электронная доска объявлений».

Проект разработан в рамках проектной работы по варианту №12.  
Приложение предоставляет возможность пользователям регистрироваться,
размещать объявления и просматривать объявления других пользователей.

## Технологии

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Microsoft SQL Server
- SSMS
- npm
- Git / GitHub

## Функциональность

### Клиент

- регистрация пользователя;
- авторизация;
- выход из системы;
- просмотр текущего пользователя;
- создание объявлений;
- указание заголовка и текста объявления;
- указание периода отображения объявления;
- просмотр списка объявлений;
- просмотр списка категорий.

### Администратор

Предусмотрена отдельная роль администратора.

Администратор должен иметь возможность:

- управлять разделами электронной доски объявлений;
- модерировать объявления;
- разрешать или запрещать пользователям размещение объявлений в определённых разделах;
- просматривать статистику размещения объявлений.

## Архитектура проекта

Проект использует Node.js и Express.js.

Фронтенд и серверная часть находятся в одном проекте.  
Клиентская часть взаимодействует с сервером через HTTP-запросы и API.

Общая схема взаимодействия:

Browser
↓
HTML / CSS / JavaScript
↓
fetch()
↓
Express.js API
↓
Controllers / Models
↓
Microsoft SQL Server

Установка

Для запуска проекта необходимо установить Node.js.

После клонирования репозитория выполнить:

npm install

Команда устанавливает зависимости проекта из package.json.

Запуск

Запустить сервер:

node server.js
